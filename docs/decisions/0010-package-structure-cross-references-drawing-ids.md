# ADR 0010 — Package structure, cross-references and drawing IDs

**Status:** Accepted 2026-10-12. Resolves tensions CV3 and T5; adds drawing IDs.

## Context and rulings

- **CV3 vs the reference package:** the author's stated order (cover → exterior → interior → power →
  I/O per card → misc) appears once per cabinet in the reference package, with a system overview
  first and device overviews last. **Ruling: adopt the per-cabinet structure.**
- **T5:** DP6 requires sheet and zone on off-page references; the reference package names the target
  drawing only. **Ruling: add sheet and zone too.**
- **New request:** LCAD should generate drawing IDs. The author does not use them today; the
  reference package numbers drawings only by their position in the drawing list, which changes when
  a drawing is inserted.

Requirements for drawing IDs, following the author's preference set by ADR 0009: digits only,
consistent, short, scalable, stable once released, and a pattern that tells the reader where the
drawing belongs.

## Decision

### 1 Package structure (CV3, DP12)

```text
Front matter (area 00):    cover + drawing list · control system overview
Per cabinet, in fieldbus order:
    exterior · interior · assemblies (harness) · power distribution ·
    I/O pages in slot order, with safety function pages after the last module they use,
    typicals, and the field I/O chains that start in this cabinet
Device overviews
Misc (catch-all; reported)
```

Terminal plans, wire lists and cable schedules are not in the drawing package for this profile; they
are delivered in the workbook and the web viewer. The BOM is a separate document.

### 2 Drawing IDs: `AATNN` (CV4, D8)

Five digits, generated by LCAD, unique within the project, locked once released [M10].

| Part | Digits | Meaning |
|---|---|---|
| `AA` | 2 | Area: `00` = front matter and package-level drawings; otherwise the cabinet's area number, the same number used by circuit wire labels (ADR 0009) |
| `T` | 1 | Drawing type: `0` cover and overviews · `1` exterior · `2` interior · `3` assemblies · `4` power distribution · `5` I/O, safety function, typical and field I/O · `6` device overview · `7`–`8` reserved · `9` misc |
| `NN` | 2 | Sequence within area and type, allocated in package order |

| Drawing | ID |
|---|---|
| Cover and drawing list | `00001` |
| Control system overview | `00002` |
| Cabinet area 10, exterior | `10101` |
| Cabinet area 10, power distribution sheets 1–2 | `10401` (sheets 1 OF 2, 2 OF 2) |
| Cabinet area 10, first I/O page | `10501` |
| Cabinet area 11, third I/O page | `11503` |

- A drawing can have several sheets (`n OF m`); the ID belongs to the drawing.
- Outside the package (file names, the web viewer, revision records) the ID is prefixed with the
  project code: `<project>-10501`. On the sheet itself the five digits are enough.
- Package order comes from the package structure, not from sorting IDs; the drawing list shows both.
- More than 99 drawings of one type in one area gets a second area number, as with wire labels.
- A device overview takes the area of the cabinet the device sits in, or `00` for devices outside
  any cabinet.

### 3 Off-page references (DP6, CV5)

Every off-page reference prints the target tag, drawing ID, sheet and zone:

```text
CR110  11501/1.C4          tag, drawing/sheet.zone
SEE 10502/1.B3  GATE LOCK OVERVIEW     a note-style reference may add the drawing title
```

Zones are row letter + column number on the 8 × 6 grid. References are derived from the model and
the sheet plan at build time, so they stay correct when drawings move or are added.

## Consequences

- Drawing IDs never change on regeneration, so printed references, redlines and the shop's paper
  copies stay valid; inserting a drawing takes the next free number in its area and type.
- Changing a cabinet's area number is a `change_convention` with an impact report, because it would
  change released drawing IDs and circuit wire labels together.
- Area `00` is reserved for package-level drawings, so no RIO station, FIO segment or cabinet area
  may be `00` (INV-20).
- The title block gains a drawing-ID field; the cover's drawing list shows the ID beside each title.
